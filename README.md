# 🎬 Streaming Service Logo Selector

A clean and customizable logo collection that lets users choose a streaming service and display its logo in the media player.

## ✨ Features

* 🎨 Choose from multiple streaming service logos
* 👀 Preview the available logos
* 🔄 Easily switch between different logos
* 📱 Clean and responsive design
* ⚡ Fast and simple logo selection
* 🌐 Use logos directly through **jsDelivr CDN**

## 📺 Supported Services

* 🔴 Netflix
* 🔵 Disney+
* 🔷 Prime Video
* ⚫ Max
* 🟢 Hulu
* 🍎 Apple TV+
* 🟡 Paramount+
* 🦚 Peacock
* 🟠 Crunchyroll
* ➕ Custom services

## 🎯 Logo Selection

```text
📺 Streaming Services


[ 🔴 Netflix ]     [ 🔵 Disney+ ]     [ 🔷 Prime Video ]


[ ⚫ Max ]          [ 🟢 Hulu ]         [ 🍎 Apple TV+ ]


                       ↓


                 ⭐ Selected Logo
```

## 🖼️ Custom Logos

Users can upload their own logo or add a custom logo asset for a streaming service.

## 👥 Community Logos

The **Community** folder is open for everyone to contribute additional **streaming service logos (PNG + GIF)** that are not already included in the main logo collection.

If you want to add a streaming service logo, please add it to the **Community** folder.

⚠️ **Please do not modify, replace, or remove anything from the first/main streaming logo folder.**

The main folder should remain unchanged, while the **Community** folder can be used for additional contributions and community-submitted streaming logos.

## ⚠️ Note

Streaming service names and logos belong to their respective trademark owners. Use logos only when you have the appropriate rights or permissions.

## 📦 CDN Links

🚀 The logos are available inside the folders of this repository.

🖼️ **Browse the folders and look at the available logo images** to find the streaming service logo you want.

🌐 Once you find the logo you want to use, **copy its jsDelivr CDN link** and use it directly in your project.

### 🔗 How it works

**1.** Open the repository and browse the logo folders.

**2.** Look at the available images and choose the logo you need.

**3.** Copy the corresponding **jsDelivr CDN link** for that image.

**4.** Use the CDN link anywhere an image URL is supported.
